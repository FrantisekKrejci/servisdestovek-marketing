# ServisDešťovek — experience map a kampaně

Podklad k prezentaci pro elektronickou komerci.

- `experience-map.pdf` — cesta zákazníka, SWOT, typologie, otisk značky, marketing na ose
- `kampane.pdf` — textové kampaně, bannery, sociální sítě, tisk, kreativa
- `kreace/` — podklady v PNG (bannery, příspěvky, billboard, plakát, leták, roll-up, štítek)

Hledanost a CPC v kampaních jsou orientační pásma, ne export z Plánovače.
